# گزارش تغییرات هوش مصنوعی چندبوم

## تغییرات این نسخه
- افزودن کامپوننت `DongGroupAI` در صفحه جزئیات هر گروه دنگ.
- ارسال نام گروه، شناسه گروه، اعضا، هزینه‌ها، پرداخت‌کننده‌ها و مشارکت‌کنندگان به‌عنوان زمینه همان گفتگو.
- جدا نگه‌داشتن تاریخچه گفتگو در state کامپوننت و پاک‌کردن آن هنگام تغییر گروه؛ اطلاعات گروه دیگر به گفتگوی گروه جدید منتقل نمی‌شود.
- استفاده از حالت مشاور مالی (`advisor`) تا دستیار گروه صرفاً تحلیل و راهنمایی کند و عملیات مالی را اجرا نکند.
- افزودن پرسش‌های پیشنهادی، وضعیت بارگذاری، خطای قابل‌نمایش و پاک‌کردن تاریخچه.
- جایگزینی Edge Function با نسخه سخت‌سازی‌شده موجود در `ai-assistant-v2` (محدودیت اندازه درخواست/تاریخچه و تأیید اجباری برای پیشنهاد عملیات).

## تست‌های انجام‌شده
- بررسی ایستا: import کامپوننت جدید و محل نمایش آن در صفحه جزئیات گروه بررسی شد.
- بررسی ایستا: نوع داده گروه ارسالی با ساختار `Group` موجود در `DongView` هم‌خوان است.
- بررسی ایستا: فراخوانی از مسیر موجود `invokeAiAssistantEdgeFunction` و حالت پشتیبانی‌شده `advisor` انجام می‌شود؛ نیازی به تغییر قرارداد فرانت‌اند/Edge Function برای mode جدید نیست.
- `tsc --noEmit` اجرا شد، اما متوقف شد پیش از بررسی سورس به دلیل نبودن dependency/type package نصب‌شده `vite/client`.
- نصب npm نیز در محیط اجرا به پایان نرسید؛ بنابراین build واقعی Vite و تست end-to-end در این محیط انجام نشده‌اند.

## نیازمند تست پس از نصب وابستگی‌ها
1. `npm install` و سپس `npm run lint` و `npm run build`.
2. ورود با حساب دارای اشتراک فعال هوش مصنوعی.
3. بازکردن گروه دنگ، پرسیدن سؤال و بررسی اینکه پاسخ از داده‌های همان گروه استفاده کند.
4. رفتن به گروه دیگر و اطمینان از خالی‌شدن تاریخچه گروه قبلی.
5. تست گروه بدون هزینه و بررسی پاسخ شفاف درباره کمبود داده.
6. بررسی quota، RLS و Edge Function در پروژه Supabase واقعی.

## محدودیت مهم
این تغییر رابط گروه‌محور را اضافه می‌کند، اما دستیار فقط به داده‌هایی که در حال حاضر در `DongView` بارگذاری شده‌اند دسترسی دارد. عضویت‌های گروهی که در فرانت‌اند به‌صورت نام ذخیره شده‌اند، به‌تنهایی هویت/UUID واقعی اعضا را اثبات نمی‌کنند. این قابلیت هزینه‌ای را ثبت یا تغییر نمی‌دهد.


## ثبت هزینه با زبان طبیعی و صدا
- در پنل هوش مصنوعی گروه، دکمه میکروفون از قابلیت گفتاربه‌متن مرورگر با زبان `fa-IR` استفاده می‌کند؛ متن تشخیص‌داده‌شده داخل کادر قرار می‌گیرد و کاربر آن را بررسی می‌کند.
- دکمه «آماده‌سازی برای ثبت هزینه» از مدل فقط پیش‌نویس ساختاریافته می‌خواهد؛ تا زمان کلیک کاربر روی «تأیید و ثبت هزینه»، هیچ ردیفی در `dong_expenses` ساخته نمی‌شود.
- پیش‌نویس شامل عنوان، پرداخت‌کننده، آیتم‌ها، مبلغ و مصرف‌کنندگان هر آیتم است و قبل از ثبت با اعضای گروه اعتبارسنجی می‌شود.
- نام‌های «من/خودم» در داده‌های نمایشی گروه به نام نمایشی حساب تبدیل می‌شوند، در صورت موجود بودن؛ اگر هویت به عضو گروه تطبیق نکند، ثبت متوقف می‌شود.
- محدودیت: گفتاربه‌متن مرورگر به پشتیبانی مرورگر و اجازه میکروفون وابسته است. برای اطمینان از استخراج JSON و اجرای end-to-end باید Edge Function واقعی و حساب Supabase پیکربندی‌شده آزمایش شود.
