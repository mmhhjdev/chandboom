# پچ اصلاح اجرای عملیات دستیار هوشمند چندبوم

## فایل‌ها
- `src/components/AIAssistant.tsx`: تأییدهای کوتاه مانند «آره»، «بله»، «اوکی» را به عملیات در انتظار وصل می‌کند؛ نام گروه/مبلغ را اعتبارسنجی می‌کند؛ در نبود ورود یا اتصال دیتابیس موفقیت جعلی نشان نمی‌دهد؛ خطاهای ثبت هزینه دنگ را بررسی می‌کند و جست‌وجوی گروه را به مالک محدود می‌کند.
- `src/context/AppContext.tsx`: خطاهای درج تراکنش در Supabase دیگر بی‌صدا نادیده گرفته نمی‌شوند و تراکنش موقت در صورت شکست از state حذف می‌شود.

## نصب
1. از دو فایل فعلی نسخه پشتیبان بگیر.
2. این فایل‌ها را در پروژه جایگزین کن.
3. از ریشه پروژه اجرا کن:
   `npm.cmd run lint`
   `npm.cmd run build`
4. در محیط آزمایشی، گروه دنگ بساز و فقط یک بار «بله» بفرست؛ سپس در جدول `dong_groups` بررسی کن که یک رکورد با اعضای درست ثبت شده باشد.

## محدودیت مهم
این پچ بر اساس سورس ZIP موجود تهیه شده و در این محیط هنوز build و اتصال واقعی Supabase اجرا نشده است. برای سایر عملیات (اهداف و یادآورها) باید توابع `addGoal` و `addReminder` در `AppContext.tsx` نیز از نظر خطاهای دیتابیس بررسی شوند؛ در صورت نیاز به تضمین ثبت واقعی همه عملیات، فایل‌های همان توابع و schema واقعی جداول باید با هم تطبیق داده شوند. این پچ موفقیت ساختگی گروه و تراکنش را کاهش می‌دهد، اما ادعای تست production ندارد.
