# اصلاح پرش ناخواسته به داشبورد

در `src/context/AppContext.tsx`، listener احراز هویت Supabase قبلاً با هر رویداد `SIGNED_IN` تب فعال را به `dashboard` تغییر می‌داد. این رویداد ممکن است هنگام بازیابی/همگام‌سازی نشست نیز رخ دهد و کاربر را وسط کار از محاسبه دنگ یا صفحه دیگری بیرون ببرد.

اکنون listener فقط وضعیت احراز هویت و داده‌های کاربر را به‌روزرسانی می‌کند و مسیر فعلی را تغییر نمی‌دهد. تغییر صفحه پس از ورود باید توسط جریان صریح رابط ورود انجام شود؛ خروج واقعی همچنان کاربر را به صفحه آغازین می‌برد. دکمه‌های ناوبری و رویدادهای back/forward مرورگر بدون تغییر باقی مانده‌اند.

## بررسی

پس از نصب وابستگی‌ها اجرا کنید:

```bash
npm run lint
npm run build
```

سپس ورود کنید، وارد محاسبه دنگ شوید و چند دقیقه منتظر بمانید یا نشست را در تب دیگری فعال کنید. صفحه نباید خودبه‌خود به داشبورد تغییر کند. Build و تست مرورگر در این محیط اجرا نشده‌اند.
